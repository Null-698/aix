# Temple Scan — local Aidoku repair

This modified source is adapted from the open-source Temple Scan extension in
https://github.com/PoppingMangoSources/popmango-aidoku-sources .

The original source states dual licensing under Apache-2.0 or MIT. Changes include
browser-backed Next.js RSC requests, explicit Cloudflare verification errors,
and a catalogue-backed homepage to replace silently empty results.

This is an unofficial user-requested compatibility repair, not the official
Aidoku Community source. Website trademarks and imagery remain with their owners.
